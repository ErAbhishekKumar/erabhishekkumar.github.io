Artificial Intelligence for Robotics Lab [162601P]

Perform all Experiments

  • Write a program in C/MATLAB/Python to design and implement a fuzzy logic controller for an autonomous mobile robot.
  • Develop programs in C/MATLAB/Python to solve inverse kinematics or optimization problems using Genetic Algorithm (GA) and Simulated Annealing (SA).
  • Write a program to solve the Travelling Salesman Problem (TSP) using the Ant Colony Optimization algorithm.
  • Implement supervised (Support Vector Machine/Decision Tree) and unsupervised (K Means Clustering) learning algorithms for robotic applications.
